Definitions required

The desk computes exactly what you define here, so this decides the answer:

  • one term per field, e.g. Type 2 diabetes = any condition with an ICD-10 code starting with E11. Common names such as “statin” or “COPD” are mapped to codes automatically;
  • optional groups or rules, e.g. Adult = aged 18 or older on 31 December 2025;
  • a final “Report per …” line naming the numbers per group, e.g. Report per region: adults, adults with type 2 diabetes and the share (%).

For records in a secure environment, define “Cohort = …” instead of a report line.

Ctrl/⌘ + Enter submits. Only the request text is processed; patient-level data never leaves the desk.
