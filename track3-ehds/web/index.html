What exactly should be counted? required

One line per definition, ending with a line that starts with “Report per …”. Doccess computes exactly what you define.

How do I write this?
  • Name each term with its code, e.g. Type 2 diabetes = any condition with an ICD-10 code starting with E11. Common names like “statin” or “COPD” are recognised automatically.
  • Add groups or rules if needed, e.g. Adult = aged 18 or older on 31 December 2025.
  • Finish with the numbers you want per group, e.g. Report per region: adults, adults with type 2 diabetes and the share (%).
  • For records in a secure workspace, define Cohort = … instead of a report line.
