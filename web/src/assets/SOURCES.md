Austria federal-state geometry is derived from Natural Earth 10m Admin 1 states and provinces GeoJSON:

https://raw.githubusercontent.com/nvkelso/natural-earth-vector/master/geojson/ne_10m_admin_1_states_provinces.geojson

Natural Earth vector data is public domain. The source is simplified locally and rounded to four decimal places by `tools/make_austria_geojson.py`. The runtime uses only the bundled `austria-states.json` file.
